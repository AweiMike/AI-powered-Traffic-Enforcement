🌓 BrandLogo 深色模式驗證

驗證 BrandLogo 4 種 variant 在各種背景下的表現，確保未來實作 dark mode 時所有場景都能正常顯示。
此頁純靜態 HTML，不依賴 React，可以直接用瀏覽器開啟檢視。

variant="dark"

深色線條。用於淺色背景（白、米、淺灰、surface-2）

variant="light"

白色線條。用於深色/彩色背景（深藍、黑、accent 藍）

variant="mono-dark"

單色深（全部同色）。用於印刷、favicon 等無法彩色場景

variant="mono-light"

單色白（全部同色）。用於極深背景 + 極簡設計

📋 使用規則總表
未來 dark mode 啟動時，各場景該用哪個 variant，一表看懂。

variant="dark" → 淺色背景（white / slate-50 / slate-100 / slate-200 / surface-2）

variant="light" → 深色背景（primary / slate-900 / slate-800 / accent / accent-hover）

variant="mono-dark" → 白底印刷、簡報黑白投影片

variant="mono-light" → 深底浮水印、極簡 dark mode 場景


⚠ 避免搭配： 任何 variant 都不建議放在 danger/warning/success 語意色背景上，會造成色彩衝突。

✓ 最佳搭配： 包裝在 bg-primary 或 bg-slate-900 的 rounded 容器裡配 light variant — 這就是目前側欄和登入頁的做法。
