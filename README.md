## 📊 指標說明

### VPI (Violation Pressure Index)
```
VPI = 違規案件數 × 主題權重

主題權重：
- 酒駕: 10.0（最高優先）
- 闖紅燈: 2.0
- 危險駕駛: 1.5
```

### CRI (Crash Risk Index)
```
CRI = 事故案件數 × 平均嚴重度

嚴重度權重：
- A1（死亡）: 5
- A2（受傷）: 3
- A3（財損）: 1
```

### Score (綜合評分)
```
Score = α × VPI + β × CRI

依主題調整：
- 酒駕: 0.7 × VPI + 0.3 × CRI
- 闖紅燈: 0.6 × VPI + 0.4 × CRI
- 危險駕駛: 0.5 × VPI + 0.5 × CRI
```

## 🔒 個資保護

### 完全去識別化

本系統在資料匯入時即進行完全去識別化：

#### 移除的個資
- ❌ 姓名
- ❌ 身分證字號
- ❌ 車號
- ❌ 電話號碼
- ❌ 完整地址（門牌號、巷弄號）

#### 保留的統計資料
- ✅ 行政區
- ✅ 路口/路段名稱（無門牌號）
- ✅ 年齡組（<18/18-24/25-44/45-64/65+）
- ✅ 性別（男/女/未知）
- ✅ 日期時間
- ✅ 班別
- ✅ 違規條款

### 資料範例

**原始地址**：
```
台南市新化區中正路123號前
```

**去識別化後**：
```
行政區：新化區
地點描述：中正路（近中山路路口）
```

**原始年齡**：
```
67歲
```

**去識別化後**：
```
年齡組：65+
是否高齡者：是
```

## 🛠️ 首次使用指南

### 步驟 1：安裝必要軟體

確保已安裝以下軟體：

- ✅ **Python 3.10+** - 後端執行環境
- ✅ **Node.js 16+** - 前端構建工具
- ✅ **PostgreSQL 14+** - 資料庫
- ✅ **PostGIS** - 地理空間擴展

### 步驟 2：設定資料庫

1. 安裝並啟動 PostgreSQL
2. 創建資料庫：
   ```sql
   CREATE DATABASE traffic_enforcement;
   CREATE EXTENSION postgis;
   ```

### 步驟 3：初始化系統

1. 雙擊 `啟動系統.bat`
2. 選擇 `[4] 初始化資料庫`
3. 等待初始化完成

### 步驟 4：匯入資料（選用）

1. 將 Excel 檔案放入 `data/` 目錄
2. 雙擊 `啟動系統.bat`
3. 選擇 `[5] 匯入資料`
4. 輸入檔案路徑

### 步驟 5：啟動系統

1. 雙擊 `啟動系統.bat`
2. 選擇 `[1] 啟動完整系統`
3. 等待瀏覽器自動開啟

## 🐛 常見問題

### Q: 啟動後看到「無法連接到資料庫」

**A**: 請確認 PostgreSQL 服務是否運行：
1. 開啟「服務」(services.msc)
2. 查找 `postgresql` 服務
3. 確認狀態為「執行中」

### Q: 前端顯示「Network Error」

**A**: 請確認：
1. 後端是否已啟動（訪問 http://localhost:8000/docs）
2. 防火牆是否阻擋了連接

### Q: Port 被佔用

**A**: 修改 port 設定：
- 前端 port：`animal-crossing-dashboard/vite.config.ts`
- 後端 port：`backend/app/main.py` 中的 `uvicorn.run()`

### Q: 資料匯入失敗

**A**: 請檢查：
1. Excel 檔案格式是否正確
2. 是否包含必要欄位（發生時間、地點等）
3. 檔案編碼是否為 UTF-8
